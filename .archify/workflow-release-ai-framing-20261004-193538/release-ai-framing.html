  • Phase 2 (config PR, change request, approval, merge) is repeated for every promotion: dev-cluster1 → all DEV → PRE-PROD → PROD, and within PRE-PROD and PROD by each regional SRE team (EU, US, APAC). This repetition drives most of the rollout effort and the "steps easily overlooked" problem.
  • Every AI agent candidate is currently blocked. Agents need written acceptance criteria and runnable tests before they can do work that SRE now does by judgement ("looks OK").
